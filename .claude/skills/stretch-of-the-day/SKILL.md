# Stretch of the Day

日本語の YouTube ストレッチ動画を毎日5本紹介する skill。
首こり / 肩こり / 姿勢改善 / お腹 / 腰背中 の5カテゴリから1本ずつ、当日の日付で決定的にローテーション選択する。

## 使い方

1. `videos.json` を読み込み、5カテゴリ(`neck` / `shoulder` / `posture` / `abs` / `back`)ごとの動画リストを取得する。
2. 今日の日付 (UTC ではなくユーザーの地域、不明なら Asia/Tokyo) を `YYYY-MM-DD` で取得し、`day_of_year` を計算する。
3. 各カテゴリで `videos[day_of_year % len(videos)]` を選び、合計5本を提示する。
   - 同じ日に再実行すると同じ5本が出る (決定的)。
   - 日付が変われば自動的に翌日のセットに切り替わる。
4. 各動画について以下を箇条書きで出力する。
   - カテゴリ(日本語ラベル)
   - タイトル
   - YouTube URL (Markdownリンク)
   - 所要時間 / 解説者・チャンネル
   - 一言コメント (どこに効くか)
5. 最後に「カテゴリを絞って欲しい / 別の動画が良い / 検索で最新を探したい」場合の案内を1行添える。

## ハイブリッド検索モード

ユーザーが以下のいずれかを希望した場合のみ `WebSearch` を使う。`videos.json` で足りる場合は検索しない。

- 「最新の動画が知りたい」「もっと新しいもの」と明示された
- `videos.json` にないテーマ(例: 足首、股関節、目の疲れなど)を求められた
- 特定のチャンネル(例: オガトレ、B-life、ヨガ等)から探したい

WebSearch を使う場合のクエリ例:
- `site:youtube.com 日本語 <テーマ> ストレッチ 解説`
- `日本語 YouTube <テーマ> ストレッチ <年>`

検索結果から候補を3〜5本選び、必ず YouTube の URL とタイトル、想定時間、チャンネル名を併記する。再生数や日付が不確実な場合はその旨を断る。

## 出力フォーマット例

```
🧘 今日のストレッチ 5本 (2026-05-15)

1. 【首こり】 ストレートネックの方にオススメのストレッチ｜8分間
   https://www.youtube.com/watch?v=TMLD9KPweRo
   約8分 / Stretch Channel
   → 首前面〜側面の硬さに。デスクワーク後におすすめ。

2. 【肩こり】 ...

(以下、姿勢 / お腹 / 腰背中 と続く)

別カテゴリだけ見たい / もっと新しい動画を探したい場合はお知らせください。
```

## 注意

- URL は `videos.json` に書かれたものをそのまま使う。勝手に URL を生成しない。
- 動画が削除されている可能性をユーザーに含み置きで伝える(リンク切れ報告を歓迎する旨を最後に1行)。
- 痛みがある場合は無理せず医療機関を受診するよう、初回起動時のみ1行で添える。
